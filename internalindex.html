This is Destination.

  1. id identifies the destination element.
  2. #id in href points to that destination.
  3. IDs should be unique within a page.
  4. You can assign an ID to a p, h1, h2, div or other suitable element.
  5. One important distinction: internalindex.html#contact navigates to another file, while #contact navigates within the current file.
